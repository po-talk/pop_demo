# 絵文字 → SVG 対応表（POP DEMO）

> **2026-10-09：pop 0.7.8 で実装しました。** 採用したのは各案の「案1」と、静かに入る＝忍者の頭巾（N2）。アイコンの定義は `icons.js`、見比べ用のページは `lab/icons.html`。
> 実装の約束：元のロジックが読む文字（textContent）は変えない。文の頭や途中の絵文字は `.lead` で隠して残し、線の絵は隣に足すだけ（index.html の `startZeroG` の「文の頭の絵文字」の節）。

POP DEMO（pop 0.7.7）で、ボタン・アイコン・印として出している絵文字を洗い出した表です（ここから下は実装前の記録）。

- 同じ意味の絵文字は 1 行にまとめています。1 行が SVG 1 つにあたります。「使っている場所」にある所は、すべて同じ SVG で差し替えられます。
- 場所の書き方：`#id` は index.html の要素、`(L123)` は index.html の行、`css:` は zerog.css です。
- 優先度：**A** 泡のボタンの中のアイコン（いちばん目立つ）／**B** 設定の選択肢／**C** 人や部屋に付く小さな印／**D** 文の中の絵文字（任意）。

## 提案：泡の世界のボタンと情報の見せ方（2026-10-08・案）

### 原則：絵文字は「いのち」、SVG は「道具」、状態は「泡そのもの」
泡の画面では、人も部屋もボタンも同じ丸い泡です。今はボタンの中身も絵文字なので、**人の泡（🐱）とボタンの泡（📮）が同じ種類のものに見えます**。そこで、中身の種類で描き方を分けます。

| 種類 | 描き方 | 例 |
| :--- | :--- | :--- |
| **いのち・気持ち**（人・気分・育つもの） | **絵文字のまま** | アバター、リアクション、育ち具合 🌱〜🌳、BGM の気分（🎵🌫🔥） |
| **道具**（押すと何かが起きるもの） | **白い線の SVG**（今ある 参加・マイク・退出 と同じ線） | ✓ ✕、タブ、コピー、QR、ヘルプ、メニュー |
| **状態**（いまどうなっているか） | **アイコンを足さず、泡の質感で表す** | 光る縁＝開いている、すりガラス＝眠っている、点線と明滅＝つながり中 |

ひと目で「顔があるのは人、白い線は押せるもの、ぼやけているのはまだ・もう無いもの」と読めるのが目標です。

### 1. ボタン（道具）
- **線は 1 種類**：24×24、白（`currentColor`）、線幅 2、端は丸め。今ある `#join` `#mute` `#leave` に合わせる。塗りは使わない（泡の透明感をつぶさない）。
- **色は役目だけ**：決める＝緑（今の `tone-ok`）、やめる・抜ける＝赤（`tone-red`）、それ以外は白。アイコンの絵ではなく、**泡の縁の色**で役目を伝える。
- **アイコンだけのボタンには、長押し（PC はマウスを乗せる）で小さな名札の泡を出す**。今は `aria-label` に書いてあるだけで、目では読めない。文字を消した UI の、いちばん大きな弱点を埋める。
- 迷う絵は**意味で描き直す**：
  - ☎️ 通話中の部屋から選ぶ → 「泡が 3 つ寄り集まった絵」（ロビーそのもの）
  - 📱 QR → QR の四角い絵（スマホの絵だと「スマホで開く」と読める）
  - 🎯 真ん中に戻る → ナビの現在地の矢印
  - 🤫 静かに入る → シー（口に指）か忍者（10-08 利用者）
  - ⚙️ 設定 → 歯車（太陽に見えない形）／➤ 送る → 横向きの紙飛行機か吹き出しに矢印／📮 おたより → ハガキか郵便ポスト／🙋 通話希望 → 指 4 本の挙手か受話器（10-08 利用者）
  - 👏 リアクションを開く → 「笑顔に＋」（中の 👏 と区別する）
  - 🫧 メニュー・ロゴ → 泡 3 粒のロゴを 1 つ作って、ハブとロゴで共用

### 2. 人の泡の印：時計の位置で役目を決める
今の配置をそのまま「決まり」にします。新しい印もこの文字盤に置けば、どの人の泡でも同じ場所を見れば分かります。

| 時計の位置 | 印 | 描き方 |
| :--- | :--- | :--- |
| 1 時 | 配信者 📣／話す人 🎙／通話希望 🙋 | **SVG**（メガホン、今ある `MIC_SVG`、今ある挙手の SVG を流用） |
| 3 時 | 話す許可を出すボタン（配信者の画面だけ） | 今の SVG のまま |
| 4〜5 時 | ミュート中 | 今の SVG のまま |
| 9〜10 時 | 無視する（ハート） | 今の SVG のまま |
| 11 時 | 中継経由／直結 | 今の SVG のまま |
| 名前の横 | 育ち具合 🌱〜🌳 | **絵文字のまま**（育つ「いのち」なので） |

「ほか N 人が聞いています」の 🙂 は、アバターと見分けがつかないので**ヘッドホンの SVG**にします（顔ではなく「聞いている人たち」の印）。

### 3. 情報：文の頭の絵文字をやめて、泡の質感と 4 色にまとめる
- **お知らせ（`showPeerNotice` など）は、下から浮かんで消える泡**にする。文頭の絵文字（🎙 📣 🔌 ⚠️ …14 種類）はやめて、**泡の色を 4 つ**に絞る。左上に小さな衛星の泡を 1 つ付け、そこにだけ SVG を入れる。
  | 色 | 意味 | 今の絵文字 |
  | :--- | :--- | :--- |
  | 青 | お知らせ | 🎙 📣 🗣 📮 👥 🛰 |
  | 緑 | うまくいった | 📋 ✓ |
  | 黄 | 気をつけて | 🔈 🔊 ⚠️（軽いもの） |
  | 赤 | 切れた・できなかった | 🔌 ❌ ⚠️（重いもの） |
- **状態は泡の質感で**（アイコンを足さない）：
  - 部屋が開いている 🟢 → 縁がやわらかく光り、中に小さな泡が立ちのぼる（今の EQ の泡）
  - 部屋が眠っている 😴 → すりガラスで少しくすみ、ゆっくり沈む
  - さがしている 🔍・ロビーに接続中 🛰 → 小さな泡が周りを回る
  - つながり中 🔄 → 点線と明滅（v0.15.22 で入れた形をほかにも使う）
- **数字は泡の形で**：
  - 部屋が開いてからの時間 ⏱ → 文字ではなく、部屋の泡の縁に沿った細い弧（時計の針のように伸びる）。正確な時間は名札で
  - 見ている人数 👥 → 背景に漂う小さな泡の数（「だいたい」の人数と相性がよい）
- **話題タグ 🏷・部屋の種類 🏠📣** は、ロビーの部屋の泡の上に乗る小さな衛星の泡（SVG）にする。名前の頭に絵文字を付けない。

### 4. 絵文字のまま残すもの
- アバター（人の顔）
- リアクション 8 個（気持ち。本家の画面とも同じ絵で見える）
- 育ち具合 🌱〜🌳
- BGM の気分 🎵🌫🔥（音楽を選ぶ＝気分を選ぶ。BGM なしだけは SVG の「音符に斜線」）
- ヘルプ・クレジットの文中の絵文字（読み物なので）
- 共有の文・部屋の名前の中の絵文字・小窓の絵

### 5. 描く数と順番（案）
1. **道具の SVG 20 個ほど**（A の全部＋設定の音量 3 段階・BGM なし・リアクション音・読み上げ・名前を読まない）と**長押しの名札**。いちばん効く
2. **人の泡の 1 時の印**（メガホン 1 個を描き足すだけ。マイクと挙手は今の SVG を流用）と、ほか N 人のヘッドホン
3. **お知らせの泡**（4 色＋衛星の SVG 4 個）
4. **状態を質感で見せる**（開いている・眠っている・さがしている）と、時間の弧・人数の泡

最初のリストアップでは「新しく描く SVG はおよそ 45 個」としていましたが、絵文字で残すものと質感で見せるものを除くと、**SVG はおよそ 30 個**になります。

## すでに SVG のもの（参考：線の太さや角の丸めをそろえる基準）
24×24・`stroke="currentColor"`・線幅 2〜2.5・端は丸め、で描かれています。

| 用途 | 場所 |
| :--- | :--- |
| 参加する | `#join` |
| 通話希望（手） | `#raise` |
| マイクを使う／ミュート | `#speak`・`#mute`・`MIC_SVG`／`MIC_OFF_SVG`（人の泡のミュート印） |
| 退出 | `#leave` |
| 小窓（PiP） | `#pip` |
| 中継経由／直結 | `CLOUD_SVG`／`ARROWS_SVG`（人の泡の経路の印） |
| 無視する／やめる | `HEART_SVG`／`HEART_BROKEN_SVG` |
| 部屋のリンクを共有 | `SHARE_SVG`（ロビーの部屋） |
| コピーした | `CHECK_SVG` |

## E. 変えないほうがよいもの
| 今の絵文字 | 理由 |
| :-- | :-- |
| アバター（`AVATARS` の 16 個・各自のプロフィール・既定の 🙂） | 利用者が選んだ「顔」。通信でそのまま送り、本家の画面にも同じものが出る |
| リアクション 8 個（👏😂✨👍🤔😮🎉🍵） | 通信では番号で送るので、POP DEMO の表示だけ SVG にはできる。ただ本家の画面には絵文字で出るので、見た目がそろわなくなる。**要相談** |
| 共有の文（クリップボードの 🫖📣・L863） | ほかのアプリに貼られる文なので、絵文字のままが正しい |
| 小窓の絵（canvas に描く 🫖・L2421） | 画像として描いている。変えるなら別の作業 |
| 部屋の名前の中の絵文字（例：やまびこ部屋⛰️） | 利用者・運営が付けた名前の一部 |
| つくよみちゃんの行の 🗣 (L1694) | 顔はすでに画像（`img/tsukuyomi-128.png`）に置き換わっている |

## 数
- A：21 種類（ボタンの数は 30 ほど）
- B：10 種類（B1 は 3 段階）
- C：11 種類（C5 は 6 段階）
- D：14 種類（任意）
- 新しく描く SVG は、A〜C で共通にできるもの（C1＝A4、C3＝B10、C4＝A3、C6＝A12 など）をまとめて **およそ 45 個**（育ち具合 6・音量 3・部屋の開閉 2 を含む）
